<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iframe envelope → coordinator | Untrusted napplet JSON crosses exact pinned-contract validation into backend authority. |
| connection/window/account → session state | Server-owned actor identity and active account determine origin, owner, and eligible recipients. |
| reducer state → delivery effects | Authority must commit before fallible WebSocket delivery and cannot be rolled back by a failed send. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Spoofing / Elevation of privilege | media coordinator actor binding | high | mitigate | Ignore client owner/account claims; derive account, connection, and window from authenticated runtime context and test foreign actors. |
| T-08-02 | Tampering | reducer generation/idempotency | high | mitigate | Exact generation comparison, bounded request fingerprints, serialized pure transition, and stale/duplicate race tests. |
| T-08-03 | Denial of service | media input/state reports | medium | mitigate | Existing 256 KB outer limit plus exact field bounds, one active session/account, bounded caches, and position-only broadcast coalescing. |
| T-08-04 | Information disclosure | projection/logging | medium | mitigate | Account-filtered effects and logs limited to message type and shortened opaque IDs; never log source, metadata, context, or account material. |
| T-08-SC | Tampering | package supply chain | high | mitigate | No installs; preserve audited exact `@napplet/core@0.31.0` and `@napplet/nap@0.31.0` aliases and contract drift tests. |
