<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket client → portal protocol | Untrusted JSON requests attempt to act as an authenticated account/window and current generation. |
| coordinator → multiple sockets | Browser-safe state must reach only current active-account recipients in deterministic order. |
| detached socket → reconnect namespace | Grace preserves origin identity but must not preserve playback ownership. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-08-07 | Information disclosure | media snapshot broadcast | high | mitigate | Resolve eligibility by active account on every send and terminalize before identity changes; test foreign-account isolation. |

</threat_model>
