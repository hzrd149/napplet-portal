| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-01 | Spoofing / Tampering | stale socket callbacks | high | mitigate | Current-socket identity plus monotonically increasing generation guards every callback and send in `shell/connection.ts`. |
| T-03-02 | Information Disclosure | reconnect token/status UI | high | mitigate | Keep token memory-only and out of DOM, status copy, telemetry, and logs; retain the existing same-origin endpoint and length bound. |
| T-03-03 | Denial of Service | retry scheduler | high | mitigate | Enforce one socket/timer, capped full jitter, lifecycle suppression, low-frequency recovery, and deterministic storm tests. |
| T-03-04 | Tampering | runtime stage projection | medium | mitigate | Advance only from validated known message shapes and never infer percentages or readiness from elapsed time. |
</threat_model>
