## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| portal snapshot → browser actuator | Browser must validate authoritative projection and stop local playback when it loses authority. |
| shell ↔ sandboxed iframe | Canonical MEDIA messages cross an authenticated WindowProxy bridge; portal coordination data must not cross. |
| media source → browser element | Shell-owned source bytes/URLs remain subject to Phase 5 backend resource policy and browser autoplay policy. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-08-09 | Tampering / Elevation of privilege | shell generation bridge | high | mitigate | Reset per socket generation, validate snapshots/results, bind current connection/window, ignore stale frames, and test iframe payload separation. |
| T-08-10 | Denial of service / safety | stale hidden playback | high | mitigate | Stop locally before applying revoked/foreign/terminal projection and on hidden state; backend generation remains authority. |
